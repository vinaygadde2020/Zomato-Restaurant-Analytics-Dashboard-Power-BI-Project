# 🍽️ Zomato Restaurant Analytics Dashboard

An interactive Power BI dashboard built to analyze Zomato restaurant data and generate business insights using data visualization techniques.

---

# 📊 Dashboard Preview

![Dashboard Preview](Dashboard%20Screenshot.png)

---

# 📌 Project Overview

This project focuses on analyzing restaurant trends, ratings, cuisines, customer votes, online ordering, and table booking availability using Power BI.

The dashboard helps in understanding customer preferences and restaurant performance through interactive visualizations and KPIs.

---

# 🚀 Tools & Technologies Used

- Power BI
- SQL
- Excel

- Data Modeling

# 📂 Dataset Details

The dataset contains information related to:

- Restaurant Names
- Locations
- Ratings
- Votes
- Cuisines
- Online Orders
- Table Booking
- Approximate Cost for Two

---

# 🏗️ Data Modeling

This project follows a proper **Star Schema Model**.

## Fact Table
- Zomato_Fact

## Dimension Tables
- Location_Table
- Cuisine_Table
- Rating_Table
- BookTable_Table
- OnlineOrder_Table

# 📈 Dashboard Features

## KPI Cards
- ⭐ Average Rating
- 🍽️ Total Restaurants
- 📍 Total Locations
- 💰 Average Cost for Two

## Interactive Visualizations
- Top Restaurants by Votes
- Rating Category Distribution
- Cuisine Distribution
- Table Booking Analysis
- Online Order Analysis
- Location vs Rating Matrix
- Cost Analysis

## Filters & Slicers
- Location Filter
- Cuisine Filter
- Rating Category Filter

---

# 🧠 Key Insights

- Majority of restaurants fall under the **"Very Good"** rating category.
- North Indian cuisine has the highest restaurant presence.
- Mid-range restaurants receive the highest customer votes.
- Most restaurants do not offer table booking facilities.
- Online ordering is highly preferred among customers.
